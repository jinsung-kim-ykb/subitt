# 구독 관리 웹앱(SUBIT) 기술 명세서 (SPEC)

## 1. 개요
20대 대학생 및 사회초년생의 불필요한 구독 지출을 줄여주는 모바일 퍼스트 PWA.

## 6. 처리 규칙
1. **가림 처리 (마스킹)**: 카드번호(12~16자리 중 앞 6자리 제외 또는 끝 4자리 제외), 성명(2~4자 이름 가운데 *), 잔액/이용가능액은 AI 전송 전 기기 내 정규식으로 마스킹.
2. **원문 저장 금지**: 원문 텍스트, 캡처 이미지는 DB, 스토리지, 서버 로그에 일절 저장하지 않음. 메모리에서 추출 후 즉시 폐기.
3. **무료체험 (A5)**: 체험 종료일(`trial_end_date`)과 자동 결제 전환 여부 감지.
4. **외화 구독 (A6 - 옵션 A)**: 결제 문자에 표기된 원화 청구 금액 우선 적용, 미표기 시 기준 환율 1,380원 적용.
5. **취소 문자 처리**: '승인취소', '결제취소' 감지 시 기존 등록된 해당 구독의 상태를 일시정지(`paused`)로 전환하거나 취소 등록 유도.

## 11. 개발 단계
- 1단계: 기반 (로그인, 오프라인 IndexedDB, 수동 등록, 환산 화면)
- 2단계: 등록 자동화 (A1 문자 파싱, A2 캡처 인식, A5 무료체험, A6 외화, S04 등록 확인, 비교 스크립트)
- 3단계: 알림과 위젯 (A3 캘린더, A4 푸시/웹훅)
- 4단계: 절약 유도 (S06 해지 가이드, S07 대안 추천)
- 5단계: 공유 및 소셜 (S08 공유 그룹, S09 챌린지)
